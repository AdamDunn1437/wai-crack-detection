# capture/ (Connor, WAI-15)

How we photograph the concrete, so every photo is taken the same way.

**Goes here**

- `checklist.md`: the one-page capture checklist (same phone, 1x, flash off, focus and exposure locked, zone card in frame, same-day upload to Drive)
- Photo box design: dimensions, photos of the build, or a 3D-print file (STL is fine here; it's small)
- `imaging-log.md`: date, who was there, which zones were shot, lighting variants, anything that went wrong
